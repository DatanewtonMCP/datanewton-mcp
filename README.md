# DataNewton MCP

DataNewton MCP connects AI assistants to information about Russian companies and individual entrepreneurs.

Датаньютон MCP позволяет AI-ассистентам получать сведения о российских компаниях и ИП: регистрационные данные, финансы, связи, судебные дела, банкротство и риск-индикаторы.

## Подключение

Сервис работает в облаке. Устанавливать сервер на свой компьютер не требуется.

- URL: `https://datanewton.ru/mcp`
- Транспорт: Streamable HTTP
- Авторизация: `Authorization: Bearer ВАШ_MCP_ТОКЕН`

Для подключения необходим тариф Датаньютон MCP и ключ доступа. Получить их можно через поддержку: info@datanewton.ru.

### Пример конфигурации

Формат настройки может отличаться в зависимости от MCP-клиента.

```json
{
  "mcpServers": {
    "datanewton-mcp": {
      "url": "https://datanewton.ru/mcp",
      "headers": {
        "Authorization": "Bearer ВАШ_MCP_ТОКЕН"
      }
    }
  }
}
```

Замените `ВАШ_MCP_ТОКЕН` своим ключом доступа. Не публикуйте настоящий ключ в GitHub.

## Примеры запросов

- Найди компанию по ИНН и покажи основные сведения.
- Проанализируй финансовые показатели компании.
- Покажи судебные дела и риск-индикаторы контрагента.
- Найди связанные с компанией организации.

Доступность данных определяется возможностями сервиса и подключённым тарифом.
